# Hospital Management System

## 1. Problem Statement
Hospitals need an organized way to store and manage patient information. Manual record management can be slow and error-prone. This project provides a web-based system to create, view, update, delete, search and manage patient records.

## 2. Objectives
- Develop a full-stack CRUD web application.
- Store patient records in a database.
- Provide a responsive user interface.
- Implement REST APIs.
- Validate user input on both frontend and backend.

## 3. Technology Stack
React, Vite, CSS, Django, Django REST Framework, SQLite, Git/GitHub.

## 4. Architecture
User → React Frontend → REST API → Django Backend → Django ORM → SQLite Database

## 5. CRUD Operations
Create: Add a new patient.
Read: Display patient records.
Update: Edit an existing patient.
Delete: Remove a patient record after confirmation.

## 6. Validation
Mandatory fields, email validation, age range validation, phone validation and unique email validation are implemented.

## 7. Testing
Test POST, GET, GET by ID, PUT/PATCH and DELETE endpoints. Also test invalid data and duplicate email errors.
